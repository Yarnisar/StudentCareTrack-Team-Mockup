# Student Care Track — ต้นแบบส่วนติดต่อผู้ใช้ (Frontend Prototype)

ต้นแบบระบบดูแลช่วยเหลือนักเรียน สำหรับงานกิจการนักเรียนและสนับสนุนผู้เรียน (Team C)
พัฒนาด้วย stack จริงของโครงงาน โดยใช้ข้อมูลตัวอย่างฝั่งไคลเอนต์แทน API ในระยะ Project 1

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| Framework | Next.js 16 (App Router) |
| ภาษา | TypeScript |
| UI | Tailwind CSS v4 + shadcn/ui (Base UI) |
| ไอคอน | lucide-react |
| ฟอนต์ | Sarabun (next/font/google) |

> Backend (FastAPI + SQLAlchemy 2.0 + PostgreSQL) จะพัฒนาใน Project 2
> โดยแทนที่ฟังก์ชันใน `src/lib/store.tsx` ด้วยการเรียก REST API ซึ่งออกแบบ signature ไว้ให้ตรงกันแล้ว

## การติดตั้งและรัน

```bash
npm install --ignore-scripts
npm run dev
```

เปิด http://localhost:3000 — หน้าแรกจะเข้าสู่หน้า Login ซึ่งเลือกบทบาทเพื่อเข้าดูต้นแบบแต่ละฝั่งได้

> หมายเหตุ: npm รุ่นใหม่บล็อก install script ของ shadcn CLI
> หากต้องการเพิ่ม component ให้ใช้ `bunx shadcn@latest add <component>`

### รันด้วย Docker (สำหรับสาธิต)

```bash
docker compose up --build
```

เปิด http://localhost:3000 — ถ้าพอร์ต 3000 ถูกใช้อยู่ให้เปลี่ยนด้วย `APP_PORT=3100 docker compose up --build`
(ใน PowerShell: `$env:APP_PORT=3100; docker compose up --build`)

- ต้องมีอินเทอร์เน็ตตอน build เพราะฟอนต์ Sarabun ดึงจาก Google Fonts
- ข้อมูลเป็นข้อมูลตัวอย่างฝั่งเบราว์เซอร์ รีเฟรชหน้าแล้วข้อมูลและบทบาทจะรีเซ็ต
- หยุดด้วย `docker compose down`

## ตรรกะทางธุรกิจที่ทำงานได้จริงในต้นแบบ

ทั้งหมดอยู่ใน `src/lib/rules.ts` อ้างอิงคู่มือการดำเนินงานระบบ HERO OBEC CARE
และหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พ.ศ. 2551

1. **การคัดกรอง 6 มิติ** — `classifyDimension()` จัดกลุ่มรายมิติตามรายการที่ติ๊ก
   - ไม่พบรายการใด → เขียว (ปกติ)
   - พบเกณฑ์เสี่ยง แต่ไม่พบเกณฑ์มีปัญหา → เหลือง
   - พบเกณฑ์มีปัญหาอย่างน้อย 1 รายการ → แดง

2. **ลำดับการประเมินสุขภาพจิต** — ระบบเลือกขั้นถัดไปจากผลลัพธ์จริง
   - Red Flag ตอบ "ใช่" ข้อใดข้อหนึ่ง → เปิด SDQ ทั้ง 3 ฉบับทันที
   - Red Flag ปกติ → ทำ 9S ต่อ
   - 9S กลุ่มใดได้ตั้งแต่ 3 คะแนน → เปิด SDQ ทั้ง 3 ฉบับ
   - 9S ปกติทุกกลุ่ม → บันทึกมิติสุขภาพจิตเป็นกลุ่มปกติ

3. **การให้คะแนน SDQ** — `scoreSdq()` คำนวณคะแนน 5 ด้าน (มีข้อคะแนนกลับด้าน)
   และแปลผลจากคะแนนรวมพฤติกรรมที่เป็นปัญหา 4 ด้าน

4. **QR Check-in เชื่อมกับโมดูลความประพฤติ** — สแกนหลังเวลา 07:30 น.
   ระบบสร้างบันทึกความประพฤติ "มาสาย" อัตโนมัติ และแจ้งเตือนเมื่อเกิน 5 ครั้งต่อเดือน

5. **สิทธิ์ตามบทบาท** — ผู้ปกครองเห็นเฉพาะข้อมูลบุตรหลานและไม่เห็นชื่อครูผู้บันทึกความประพฤติ

## ข้อควรทราบสำหรับการสาธิต

- สถานะทั้งหมดเก็บในหน่วยความจำของเบราว์เซอร์ **การรีเฟรชหน้าจะรีเซ็ตกลับเป็นข้อมูลตั้งต้น**
